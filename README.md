# תעודות משלוח — תאגיד הרי נצרת

אפליקציית שטח דיגיטלית להנפקת תעודות משלוח (חשבוניות משלוח) לנהגים וכלי שטח.

## תכונות

- **מספור ייחודי** — כל תעודה מקבלת מספר ייחודי בפורמט: `תאריך-שעה-חתימת_מכשיר-מונה`
  - דוגמה: `20260906-07-1847-0001` = 6 בספטמבר 2026, שעה 07, תעודה #1 של המכשיר
  - החתימה הייחודית (4 ספרות) מיוצרת אוטומטית בפעם הראשונה
  - מובטח שלא יהיו כפילויות גם כשמספר אנשים עובדים במקביל
- **עותק בטלפון** — שמירה מקומית בIndexedDB, זמינה גם בלי רשת
- **חתימה** — צילום חתימה באצבע על קנבס
- **תמונות** — צירוף עד 12 תמונות לתעודה
- **היסטוריה** — חיפוש וצפייה בתעודות קודמות
- **ריכוז תקופתי** — ייצור קובץ HTML/PDF מרוכז, CSV, וסיכום וואטסאפ
- **גיבוי ושחזור** — ייצוא ויבוא של כל הנתונים

## שימוש

פתח את `delivery/index.html` בדפדפן. כל הנתונים נשמרים מקומית בדפדפן.

בפעם הראשונה:
- המערכת תיצור **חתימה ייחודית** (4 ספרות) עבור המכשיר הזה
- חתימה זו משמשת בכל מספר תעודה כדי למנוע כפילויות

**הגדרות אופציונליות:**
1. עבור לטאב "הגדרות"
2. הגדר שם נהג ומספר רכב כברירת מחדל (כדי שלא תצטרך להקליד בכל פעם)
3. שמור

## העלאה ל-GitHub Pages

כדי להפוך לאתר פרום-אונליין:

```bash
git remote add origin https://github.com/YOUR_USERNAME/delivery-notes.git
git push -u origin main
```

לאחר מכן עבור להגדרות הריפו ב-GitHub והפוך את main ל-Pages source. האתר יהיה זמין ב:
```
https://YOUR_USERNAME.github.io/delivery-notes/
```

או

```
https://your-custom-domain.com/delivery-notes/
```
